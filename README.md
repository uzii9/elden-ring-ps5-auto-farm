# elden-ring-ps5-auto-farm
PS4/5 Elden Ring Zen automated Albinaurics farm, the first of it's kind.



This Cronus Zen GPC script automates the popular Albinaurics rune farming method in *Elden Ring*, originally available for Xbox but now ported for PS5 (DualSense). 


##  Features
- Toggle loop on/off using R3
- Precisely timed character movements, more optimized and efficient then the xbox version:)
- Infinite farming loop
- PS5/DualSense compatible (runs under PS4 controller emulation)


##  Technical Details

- Written in [GPC](https://cronusmax.com/manual/gpc_language_reference.htm) (GamePack Compiler) for Cronus Zen
- Developed using Zen Studio
- Input logic optimized for *Elden Ring*. 

##  Usage
1. Open Zen Studio and create a new GPC script
2. Paste the contents of `ps5eldenring.gpc`
3. Flash to your Cronus Zen device
4. (YOU MUST MEET THE PREREQUISITES, HAVE ALBINAURIC WAYPOINT UNLOCKED) Press R3 in-game to start or stop the loop



*Note: Use responsibly :)
